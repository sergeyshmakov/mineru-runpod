## How it works

This is an open-source repo and [RunPod Hub](https://runpod.io?ref=31jdfpnq) template — not a hosted service. Deploy it from the Hub (or fork it for full control), and the worker runs on **your** RunPod account against **your** wallet.

Under the hood it is one Docker image wrapping [MinerU](https://github.com/opendatalab/MinerU) 3.4.x with the `MinerU2.5-Pro-2605-1.2B` VLM by default. Send a PDF as a URL, base64 blob, or path on a mounted volume. Get back Markdown, a structured `content_list`, the raw `middle.json`, and extracted images. When traffic stops, RunPod tears the worker down in seconds.

## Try it in 30 seconds

```python
from mineru_client import MineruClient

client = MineruClient(endpoint_id="<your-endpoint-id>")
result = client.parse_document(file_url="https://example.com/report.pdf", end_page=4)
client.save_tarball(result, "./out/doc")
# → markdown + content_list + middle.json + images
```
